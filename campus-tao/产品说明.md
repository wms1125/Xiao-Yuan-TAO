## 一、产品概述

**校园淘**是一个面向高校场景的**校园二手交易平台**，为学生提供二手商品的发布、浏览、加购、下单、支付、发货、收货、评价与售后退款的**完整交易闭环**。

- **产品定位**：让校园闲置物品在同学之间高效、安全地流转。
- **产品形态**：B/S 架构 Web 应用（管理后台式界面），前后端分离。
- **适用场景**：毕业生处理闲置、学长学姐转让教材/电器/生活用品、校内低价好物交易。
- **配套能力**：系统内置完整的后台管理能力（用户、角色、菜单、日志、监控等若依原生模块），并针对交易场景做了企业级加固（防超卖、支付幂等、事务一致性等）。

## 二、目标用户与核心价值

| 角色 | 说明 | 核心诉求 |
|------|------|----------|
| 卖家（在校学生） | 发布闲置商品 | 快速发布、方便管理上下架、卖出收款 |
| 买家（在校学生） | 浏购二手商品 | 分类浏览、加购比价、下单支付放心 |
| 平台管理员 | 运营与治理 | 商品审核、售后仲裁、系统监控 |

**核心价值**：
1. 一站式完成「发布 → 交易 → 收款 → 售后」全流程，无需线下私下沟通。
2. 沙箱支付账户 + 售后退款机制，保障买卖双方资金安全。
3. 库存防超卖 + 订单状态机，保证高并发下交易数据一致。

## 三、功能总览

登录后左侧菜单「校园淘」包含六大业务页面：

| 模块 | 路径 | 功能要点 |
|------|------|----------|
| 商品管理 | `/campus/product` | 发布/编辑/删除商品，上下架开关，**加入购物车**；支持标题、价格、原价、成色（1~5 星）、描述、图片、库存 |
| 分类管理 | `/campus/category` | 分类的新增/编辑/删除，支持父子层级（parent_id）与排序 |
| 购物车 | `/campus/cart` | 勾选/修改数量/删除/**去结算**（下单弹窗，一键生成订单） |
| 我的订单 | `/campus/order` | 订单列表（展开查看订单项明细）；操作：**支付 / 取消 / 发货 / 确认收货 / 申请售后 / 评价** |
| 支付账户 | `/campus/account` | 沙箱余额展示 + 演示充值（无真实第三方支付，符合模拟支付要求） |
| 售后管理 | `/campus/aftersale` | 售后单列表 + 管理员审核；**审核通过自动退款并回补库存** |

另内置若依后台管理：用户/角色/菜单/部门/岗位、字典、参数、通知公告、操作日志、登录日志、在线用户、定时任务、缓存监控、服务监控、代码生成等。

**后端接口域**：`/campus/product`、`/campus/category`、`/campus/cart`、`/campus/order`、`/campus/account`、`/campus/aftersale`、`/campus/review`。

## 四、核心业务流程

**正向交易链路**：

```
发布商品 → 加入购物车 → 去结算（下单，预占库存）
        → 支付（沙箱扣余额）→ 发货 → 确认收货 → 评价
```

**逆向售后链路**：

```
订单「申请售后」→ 售后管理「审核通过」→ 自动退款（余额回滚）+ 自动回补库存
```

**订单状态机**（服务层强约束，非法跃迁直接拒绝）：

```
0 待付款 → 1 已付款/待发货 → 2 已发货 → 3 已完成
             ↘ 4/5/6 异常态（取消/售后中等）
```

## 五、技术架构与选型

| 层 | 技术 | 说明 |
|----|------|------|
| 前端 | Vue 3.5 + Vite + Element Plus 2.13 + Pinia + Axios + ECharts | 端口 8088，`/dev-api` 代理转发至后端 |
| 后端 | Spring Boot 4.1 + JDK 17 + MyBatis + Spring Security + JWT | 端口 8080，若依 RuoYi-Vue 3.9.2 |
| 数据库 | MySQL 8.0.40 | 库名 `campus_tao`：33 张系统表 + 8 张业务表 |
| 缓存 | Redis（内嵌 embedded-redis） | 应用启动自动拉起 6379，进程退出自动关闭，**无需单独安装** |
| 连接池 | Druid | 带监控页面 |
| 代码组织 | `com.ruoyi.campus` 独立包 | domain / mapper / service / controller 四层，不污染若依原生代码 |

**部署形态**：本发行包（campus-tao-dist）自带 JDK 17 与 MySQL 8.0.40，配合三个一键脚本，可在纯净 Windows 机器上开箱运行。

## 七、企业级能力（六维加固）

1. **安全**：Spring Security + JWT 登录鉴权；写接口 `@PreAuthorize` 权限校验，无权限返回 403；当前用户身份一律取自服务端 `SecurityUtils`，**下单/支付/评价归属人不可被前端篡改**；「我的」数据接口做归属校验，防止横向越权；JWT 密钥支持环境变量注入（`${JWT_SECRET:...}`）；登录验证码开关化（`sys_config`）。
2. **一致性**：下单、支付、取消、发货、收货、售后审核全部 `@Transactional(rollbackFor)`，**库存扣减与订单落库同事务**，杜绝「钱退了库存没回」。
3. **可靠性**：
   - **防超卖（乐观锁）**：`UPDATE ... SET stock=stock-?, version=version+1 WHERE id=? AND stock>=?`，并发下库存不足直接拦截回滚（已专项验证）；
   - **账户扣款原子化**：`UPDATE ... SET balance=balance-? WHERE user_id=? AND balance>=?`，余额不足影响行数为 0，杜绝并发超扣；
   - **支付幂等**：对已付款订单重复调用支付直接返回成功，防网络重试重复扣款；
   - **订单状态机**：非法状态跃迁（如对非待付款订单支付）直接拒绝。
4. **性能**：Redis 缓存（验证码/令牌/配置）；MyBatis 物理分页（`startPage()`）；Druid 连接池。
5. **工程化**：四层清晰分层（domain/mapper/service/controller + dto）；请求参数 DTO + Jakarta Bean Validation（`@Validated`/`@Valid`）；统一 `AjaxResult` 响应 + 前端拦截器；业务异常统一抛 `ServiceException`，另有 `@RestControllerAdvice` 低优先级兜底；含可运行的 JUnit 5 单元测试。
6. **运维**：关键步骤日志留痕；启动期打印端口与内嵌 Redis 状态；Druid 监控页观测数据源；`ai-log/` 全程 AI 辅助留痕。

## 十、已知限制与生产建议

| 项 | 现状 | 生产建议 |
|----|------|----------|
| 支付 | 沙箱余额模拟，未对接第三方支付 | 接入微信/支付宝沙箱或正式渠道 |
| 登录验证码 | 演示环境已关闭（`sys_config` 置 `false`） | 上线前改回 `true` 并重启后端 |
| 接口权限 | 仅商品/分类/评价的列表与详情读接口 `@Anonymous`（便于未登录浏览） | 按需收紧，保留 `@PreAuthorize` 与归属校验 |
| JWT 密钥 | 支持 `${JWT_SECRET:...}`，交付包内为演示默认值 | 生产通过环境变量注入独立强密钥 |
| 并发锁 | 数据库行锁/乐观锁（单机足够） | 多实例部署时升级分布式锁 |
| 部署路径 | Windows 本机发行包形态 | 可容器化（MySQL/Redis/后端/前端分容器编排） |
