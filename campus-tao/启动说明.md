# 校园淘（校园二手商城）本地启动说明

> 技术栈：若依 RuoYi-Vue 3.9.2（Spring Boot 4.1 + JDK 17）+ Vue3（Vite）+ MySQL 8.0.40
> 本说明基于本机隔离环境（所有依赖装在 `C:/Users/eric/Desktop/ai第四次` 与 `.workbuddy/tools`，不污染系统）。
>
> **交付版启动方式**：本发行包 `campus-tao-dist` 已内置 JDK 17 与 MySQL 8.0.40，**无需安装 Maven**；依次双击 `1-初始化数据库.bat` / `2-启动后端.bat` / `3-启动前端.bat` 即可，详见 `../同学运行指南.md`。下文为作者本机环境的原始记录，保留供排查参考。

## 一、环境前置（一次性）
- JDK 17：`ai第四次/jdk-17`（Adoptium 17.0.20.1）
- Maven 3.9.9：`.workbuddy/tools/apache-maven-3.9.9`

## 三、启动后端（端口 8080）
必须用 `java -jar` 方式（不要用 `mvn spring-boot:run`，后者在 devtools 重启下会抢占随机端口）：

验证：`curl http://localhost:8080/captchaImage` 返回 200 且含 base64 图片即成功。

## 四、启动前端（端口 8088，系统已占用 80）
> 系统进程（PID 4）占用了 80 端口，因此前端 dev 端口改为 **8088**。
> `vite.config.js` 的 `port: 80` 已改为 `port: 8088`，后端地址 `http://localhost:8080` 不变。

**1) 先起本地 npm 代理（沙箱对 npm CLI 外部网络限速，直连会卡死）**
```bat
cd ai第四次\campus-tao-ui
node npm-proxy.cjs
```
该代理监听 `localhost:4777`，把请求转发到 tencent npm 镜像并改写 tarball 地址，
让 npm 只与 localhost 通信（不限速）。非沙箱环境可跳过，直接用 `npm install --registry=https://registry.npmmirror.com` 直连。

**2) 安装依赖并启动**
```bat
cd ai第四次\campus-tao-ui
npm install --registry=http://localhost:4777/ --prefer-offline --no-audit --no-fund
npm run dev
```
浏览器打开 `http://localhost:8088`（默认账号 admin / admin123）。
前端通过 Vite 代理把 `/dev-api` 转发到 `http://localhost:8080`。

> **踩坑①**：原 `package.json` 依赖 `sass-embedded`，其安装脚本会从 GitHub 下载原生二进制，
> 本机 GitHub 不通会卡死 `npm install`。已改为纯 JS 的 `sass`（同版本区间），
> 二进制从 npm 镜像完整下载，无外部依赖。改文件：`campus-tao-ui/package.json`。
> **踩坑②**：`npm install` 一定要在 `campus-tao-ui` 目录内执行；若 cwd 错（无 package.json），
> 会报 `NPM_EXIT=127` 且不会安装任何东西。用 `--prefer-offline` 可命中本地缓存、避免 safe-delete 报错。

## 五、关键约定（避免踩坑）
1. **Redis 不装外部版**：本机禁 WSL/Docker、GitHub 不通，`embedded-redis` 是唯一可复现路径。
2. **禁用 devtools 热重启**（`application.yml` 中 `spring.devtools.restart.enabled=false`）：
   devtools 重启会令 Tomcat 落到随机端口，前端代理 8080 会连不上。
3. **上传路径改为相对路径**：`application.yml` 的 `ruoyi.profile` 已改为相对路径 `./uploadPath`
   （相对后端进程工作目录，随发行包移动而移动；原值 `D:/ruoyi` 不存在，jar 内配置也已同步刷新）。
4. **JAVA_HOME 用 Windows 风格路径**（`C:/...`，含中文父目录可被 cmd 识别），不要用 Git Bash 的 `/c/...`。

### 八.1 可选：启用短信/邮件外呼与物流轨迹查询

站内通知为**必达链路**；短信/邮件外呼与物流轨迹为**可选增强链路**，网关地址未注入时自动视为「未启用」并降级（下单、发货等主流程不受影响），降级情况仍会在「通知外呼日志」页留痕（结果为「未启用」）。启用方式是在启动后端前注入环境变量（密钥不落配置文件）：

```bat
set CAMPUS_SMS_ENDPOINT=https://<短信网关>/send
set CAMPUS_SMS_APP_KEY=<应用密钥>
set CAMPUS_SMS_SIGN=校园淘
set CAMPUS_MAIL_ENDPOINT=https://<邮件网关>/send
set CAMPUS_MAIL_APP_KEY=<应用密钥>
set CAMPUS_MAIL_FROM=noreply@example.com
set CAMPUS_LOGISTICS_ENDPOINT=https://<物流网关>/query
set CAMPUS_LOGISTICS_APP_KEY=<应用密钥>
set CAMPUS_LOGISTICS_CARRIER=SF
```

网关约定为 `application/x-www-form-urlencoded` 表单提交，响应 `code=0`（或 `success=true`）视为成功；短信表单字段 `appKey/sign/mobile/content`、邮件 `appKey/from/to/subject/content`、物流 `appKey/carrier/logisticsNo`（响应 `traces[{time,status,context}]`）。物流轨迹另有每 30 分钟一次的定时同步任务 `校园淘-物流轨迹自动同步`，可在「系统监控 → 定时任务」中启停或手工触发。

## 十一、生产部署（Nginx + 后端 jar）

本章为**生产环境**部署参考；本地演示仍用第一章的三步启动脚本。

### 11.1 前置校验（必做）
生产制品必须来自"校验通过"的提交，不允许手工绕过门禁：
```bat
cd campus-tao-dist
verify.bat
```
`verify.bat` 与 CI（`.github/workflows/ci.yml`）等价，5 步全过（退出码 0）才可发布：
后端打包 → 后端单测 + **jacoco 覆盖率门禁**（行 ≥35% / 分支 ≥18%）→ 前端单测 + **v8 覆盖率门禁**（行 ≥25%）→ 前端生产构建。
CI 另含「依赖漏洞扫描」job：前端 `npm audit --omit=dev`（要求 0 告警）+ 后端 `osv-scanner` 扫 `sbom/backend-bom.json`。

### 11.2 构建制品
| 制品 | 来源 | 产物 |
|------|------|------|
| 前端静态资源 | `campus-tao-ui` 执行 `npm run build:prod` | `campus-tao-ui/dist/`（含 `.gz` 预压缩文件；接口前缀 `/prod-api`，见 `.env.production`） |
| 后端可执行包 | `campus-tao/RuoYi-Vue-master` 执行 `mvn -B verify` | `ruoyi-admin/target/ruoyi-admin.jar` |
| 覆盖率报告 | 上述两条命令附带产出 | `ruoyi-system/target/site/jacoco/index.html`、`campus-tao-ui/coverage/index.html` |

### 11.3 服务器目录约定
```
/usr/share/nginx/campus-tao-ui/     # 前端 dist 内容（nginx root）
/opt/campus-tao/app/ruoyi-admin.jar # 后端 jar
/opt/campus-tao/uploadPath/         # 上传目录（对应 ruoyi.profile，须与进程工作目录一致）
/etc/nginx/conf.d/campus-tao.conf   # 反代配置（取自本仓库 deploy/nginx.conf）
```
后端必须**在 `/opt/campus-tao/app` 下启动**：`ruoyi.profile` 配置为相对路径 `./uploadPath`，工作目录变了上传目录会跟着变。

### 11.5 Nginx 配置与生效
```bash
cp deploy/nginx.conf /etc/nginx/conf.d/campus-tao.conf
# 按实际环境替换：server_name、证书路径、root、upstream 端口
nginx -t && nginx -s reload
```
配置要点（完整见 `deploy/nginx.conf`）：
- `/prod-api/` → `http://127.0.0.1:8080/`（`proxy_pass` 末尾 `/` 负责剥离前缀）；
- `/profile/` → 后端，读取上传文件；
- `/static/`、`/campus-img/` 长缓存，`index.html` 不缓存；SPA 路径回落 `try_files ... /index.html`；
- `gzip_static on` 直接复用构建期的 `.gz` 预压缩文件；
- `/actuator/health`、`/v3/api-docs`、`/swagger-ui` 仅内网可访问；
- HTTP 80 仅用于跳转 HTTPS 与证书校验，主站走 443。
