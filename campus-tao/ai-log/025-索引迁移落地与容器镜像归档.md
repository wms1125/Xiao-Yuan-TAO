# 025 · 收口 v1.0.21 的两项「未纳入」：索引迁移落地 + 容器镜像归档

## 1. 目标与结论
v1.0.21 的 CHANGELOG 明确记录了两项未完成项：

1. **候选索引 DDL 未落地交付库**——性能报告里的 4 条复合索引只存在于 `perf/idx-candidate.sql`，交付库并未受益；
2. **容器镜像未归档**——CI 的 `docker` job 只验证「能构建、能起栈」，未推镜像仓库、无 digest。

本轮把两项收口。**结论**：`V4__product_order_indexes.sql` + `U4` 已纳入版本化迁移并在本地完成全链路验证；`release-image.yml` 在 `v*` tag 上推送 GHCR 并产出 digest，随 Release 归档。

## 2. 关键实现

### 2.1 V4 索引迁移（4 条复合索引）
- 落地索引：`campus_product.idx_status_time (status,create_time)`、`idx_seller_time (seller_id,create_time)`、`idx_category_status_time (category_id,status,create_time)`、`campus_order.idx_user_time (user_id,create_time)`。
- 设计原则与性能实验一致：**过滤列与 `create_time` 编进同一索引**，消除 `Using filesort` 并转为 `Using index`。
- **幂等实现**：MySQL 8.0 不支持 `CREATE INDEX IF NOT EXISTS`，故先查 `information_schema.STATISTICS`，命中则 `DO 0`、未命中则 `PREPARE/EXECUTE` 执行 `ALTER TABLE`。`U4` 用同样的守卫反向处理。
- 迁移验证链 `db/tools/verify_flyway.sh` 由 V3 扩到 V4：版本断言 `1,2,3,4`、表数 47，并在「空库迁移 / 回滚后 / 重放后」三处断言 4 条索引。
- **断言的坑**：`campus_search_history` 也有一个同名 `idx_user_time`，裸判会假通过；断言必须带 `table_name` 限定与 `seq_in_index=1`。
- `sql/campus_tao_full.sql` 同步补入 4 条索引，使**存量库升级（V4）**与**全量脚本新建**两条路径口径一致——否则新建库反而没有索引。

### 2.2 容器镜像归档（GHCR + digest）
- 新增 `.github/workflows/release-image.yml`，与 `ci.yml` 的 `docker` job **职责分离**：CI 只验证可构建可起栈，新 workflow 只负责发布。
- 矩阵构建 `campus-tao-backend` 与 `campus-tao-ui`，推送 `ghcr.io/<owner>/<image>:<version>` 与 `:latest`，`build-push-action` 输出 digest。
- `permissions` 显式声明 `contents: write` + `packages: write`，不依赖默认权限。
- digest 双份留痕：Actions artifact + Release 资产 `campus-tao-images-v<version>.txt`（record job 等待 Release 创建，最多约 20 分钟）。

### 2.3 顺带修复的漂移
- `docker-compose.yml` 两处 `APP_VERSION:-1.0.17` → `1.0.22`；「V1/V2 迁移」注释 → 「V1~V4」。
- `application.yml` 的 `info.app.version` 发布前先升到 `1.0.22`（v1.0.21 曾因先打 tag 后改版本而被迫移动 tag）。

## 3. 验证
- 空库：`Successfully applied 4 migrations ... now at version v4`；`flyway_schema_history = 1,2,3,4`；表数 47；索引 4/4。
- 幂等：U4 → 0，再执行 U4 → 仍 0；重放 V4 → 4，再执行 V4 → 仍 4。
- 交付库 `campus_tao`：v3 → v4，索引 4 条落地。
- CI：`flyway` job 在真实 bash 上执行含 4 版本与 3 处索引断言的新版脚本；`release-image` 在 tag 上实跑。
